# Text Masking

テキストの一部を伏せ字などに置き換える、ブラウザだけで動くテキストエディタです。置き換える語（置換ワード）をタグで登録しておき、置換スイッチを ON にすると、置き換えたあとのテキストを表示・コピーできます。

人名やメールアドレスなどを伏せてから、チャットや issue に文章を貼りたいときに使います。

## できること

- 登録した語をテキストの中から探し、黄色のマーカーで示す
- 置換スイッチを ON にすると、置き換えたあとのテキストを表示する（置き換えた箇所は薄い青）
- 表示中のテキスト（OFF なら元の文、ON なら置き換えたあとの文）をワンクリックでコピーする
- 置き換えたあとの値は、自動で伏せ字にする。手で書き換えることもできる
- 置換ワードごとに、有効・無効を切り替える
- 置換ワードを検索・絞り込みする（すべて / 有効 / 無効）

### 伏せ字の決まり

最初と最後の 1 文字を残して、あいだの文字を伏せます。半角の文字は `*`、全角の文字は `＊` にします。記号・空白・数字はそのまま残します。

| 置換前               | 置換後                       |
| -------------------- | ---------------------------- |
| `山田太郎`           | `山＊＊郎`                   |
| `tanaka@example.com` | `t*****@*******.**m`         |
| `山田`               | `山＊`                       |
| `ＡＢＣ１２３`       | `Ａ＊Ｃ１２３`               |
| `03-1234-5678`       | `03-1234-5678`（すべて残す） |

### 置き換え方

- 完全に一致する部分だけを置き換えます。大文字と小文字は区別します。
- 複数の置換ワードに当てはまるときは、長いほうを優先します。
- 置き換えたあとの文字が、さらに別の置換ワードで置き換わることはありません。

## 導入方法

インストールは不要です。ブラウザで次の URL を開きます。

https://nameofsummer.github.io/pages-text-masking/

### 手元で動かす

Node.js 26 以上が必要です。

```bash
npm ci
npm run dev
```

表示された URL をブラウザで開きます。

## 使い方

1. 右（画面が狭いときは下）の「置換ワード」の入力欄に、伏せたい語を入れて Enter を押す。タグとして追加される
2. 左（画面が狭いときは上）の「テキスト」に文章を貼り付ける。置換ワードに一致した箇所が黄色になる
3. **置換** スイッチを ON にする。置き換えたあとのテキストが表示される
4. **コピー** を押して、置き換えたあとのテキストをコピーする

### 置換ワードの操作

| 操作                            | 内容                                                                 |
| ------------------------------- | -------------------------------------------------------------------- |
| 入力欄で Enter                  | 置換ワードを追加する（同じ語がすでにあるときは、そのタグが点滅する） |
| タグにマウスを載せる            | 置き換えたあとの値を吹き出しで表示する                               |
| タグを押す                      | 編集欄を開き、置換前・置換後・有効を変える                           |
| 編集欄の矢印ボタン              | 置換後を自動の伏せ字に戻す                                           |
| 編集欄のごみ箱ボタン / タグの × | 置換ワードを削除する                                                 |
| 入力欄が空のときに Backspace    | 最後のタグに移る。タグの上で Backspace / Delete を押すと削除する     |
| Esc / 編集欄の外を押す          | 編集欄を閉じる                                                       |

- 置換後を手で書き換えたタグには、オレンジの小さな点が付きます。
- 置換ワードは 200 件まで、置換前・置換後はそれぞれ 200 文字まで登録できます。
- テキストと置換ワードのあいだの区切りバーをドラッグすると、幅（画面が狭いときは高さ）を変えられます。キーボードでは Tab でフォーカスし、矢印キーで動かします。

## 保存されるもの

| 対象                                               | 保存                               |
| -------------------------------------------------- | ---------------------------------- |
| 置換ワード（置換前・置換後・有効かどうか・並び順） | ブラウザ（localStorage）に保存する |
| 区切りバーの位置                                   | ブラウザ（localStorage）に保存する |
| テキスト本文                                       | **保存しない**                     |
| 置換スイッチの ON / OFF                            | 保存しない（開くたびに OFF）       |
| 検索・絞り込み                                     | 保存しない                         |

テキスト本文はどこにも送信・保存しません。伏せたい文章がブラウザに残らないようにするためです。置換ワードは保存されるので、共用の PC では使い終わったら削除してください。プライベートブラウズなど localStorage が使えない環境では、置換ワードも保存されません。
